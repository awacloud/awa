# i18n

> Translation catalogs, `{key}` interpolation, `Intl.PluralRules` plurals, locale-aware formats.

**Module** `i18n` | **Source** `packages/front/fw/src/io/i18n/i18n.js` | **Deps** none | **Worker-safe** yes

No async catalog loading (the caller passes the object) — no full ICU MessageFormat (only `{token}` + simple plurals).

## Resolve

```js
const i18n = runtime.resolve('i18n');
const tr = i18n.create({
    locale: 'fr-FR',
    fallback: 'en',
    catalogs: { 'fr-FR': { ... }, en: { ... } }
});
// Returns: { t, tn, has, setLocale, addCatalog, format, locale, fallback }
```

## API

| Method | Signature | Returns |
|--------|-----------|---------|
| `create` | `({ locale?, fallback?, catalogs? }) => I18n` | New instance |
| `tr.t` | `(key: string, params?) => string` | Translates and interpolates |
| `tr.tn` | `(key: string, count: number, params?) => string` | Plural via Intl.PluralRules |
| `tr.has` | `(key: string) => boolean` | Key present in current locale (no fallback) |
| `tr.setLocale` | `(locale: string) => void` | Changes the active locale |
| `tr.addCatalog` | `(locale: string, dict: object) => void` | Deep merge into the catalog |
| `tr.format` | `(value, type: string, options?) => string` | Locale-aware Intl format |
| `tr.locale` | getter `string` | Active locale |
| `tr.fallback` | getter `string` | Fallback locale |

### `format` types

| Type | Description | `value` |
|------|-------------|---------|
| `'number'` | Intl.NumberFormat | `number` |
| `'currency'` | Intl.NumberFormat style currency | `number` |
| `'date'` | Intl.DateTimeFormat | `Date` |
| `'relative'` | Intl.RelativeTimeFormat | `number` (+ `options.unit`) |

## Examples

### Translation + interpolation

```js
const i18n = runtime.resolve('i18n');
const tr = i18n.create({
    locale: 'fr-FR',
    fallback: 'en',
    catalogs: {
        'fr-FR': {
            greeting: 'Bonjour {name}',
            items: { one: '{count} article', other: '{count} articles' },
            nested: { menu: { open: 'Ouvrir' } }
        },
        en: { greeting: 'Hello {name}' }
    }
});

tr.t('greeting', { name: 'Alice' }); // 'Bonjour Alice'
tr.t('nested.menu.open');            // 'Ouvrir'
tr.t('missing.key');                 // 'missing.key' (key returned as-is)
```

### Pluralization

```js
tr.tn('items', 1);  // '1 article'
tr.tn('items', 5);  // '5 articles'
tr.tn('items', 0);  // '0 articles' (fr-FR: 0 → 'other' or 'one' depending on impl.)
```

### Locale switch + catalog addition

```js
tr.setLocale('en');
tr.t('greeting', { name: 'Bob' }); // 'Hello Bob'

tr.addCatalog('es', { greeting: 'Hola {name}' });
tr.setLocale('es');
tr.t('greeting', { name: 'Carlos' }); // 'Hola Carlos'
```

### Locale-aware formats

```js
tr.format(1234567.89, 'number', { maximumFractionDigits: 2 }); // '1 234 567,89' (fr-FR)
tr.format(99.9, 'currency', { currency: 'EUR' });              // '99,90 €'
tr.format(new Date(2024, 0, 15), 'date', { dateStyle: 'long' });
tr.format(-1, 'relative', { value: -1, unit: 'day' });         // 'hier'
```

## Worker Usage

```js
const worker = fw.createWorker(
    function ({ libs, args }) {
        const tr = libs.i18n.create({ locale: args[0], catalogs: args[1] });
        self.postMessage(tr.t(args[2], args[3]));
    },
    { dependencies: ['i18n'], args: ['fr-FR', catalogs, 'greeting', { name: 'Alice' }] }
);
```

## Notes

- `t('key')` never throws — returns the key if not found in locale + fallback.
- `tn` requires a key pointing to an object with plural branches (`one`, `other`, `few`, `many`, `zero`, `two`) — does not fall back to `t` if the value is a string.
- `addCatalog` performs a deep merge: existing keys are preserved, new ones are added, conflicts are replaced by the new value.
- Async loading: `fetch('/locales/fr.json').then(d => tr.addCatalog('fr-FR', d))`.
- No HTML escaping in `{token}` — XSS is possible if params come from user input and the result is injected into the DOM via `innerHTML`.
