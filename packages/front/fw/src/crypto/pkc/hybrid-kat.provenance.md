# Hybrid combiner KAT — provenance lock

Provenance record for every committed vector/fixture consumed by the fw hybrid
PQC combiner suites (`crypto/pkc/hybridKem` X-Wing, `crypto/pkc/hybridSign`
composite) and by the reproducible combiner-KAT regeneration
(`tools/hybrid-kat-regen.js`). Entries are **per file**. `SHA-256` is computed
over the committed file bytes (LF newlines).

Regenerate / re-verify the derived combiner KATs (deterministic, no network):

```bash
bun packages/front/fw/tools/hybrid-kat-regen.js         # exit 0 = byte-identical
```
