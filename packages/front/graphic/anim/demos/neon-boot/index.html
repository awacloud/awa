SVG animation that boots without a build.

Neon Grid is one SVG scene. One Timeline plays the 11 s boot; everything that keeps moving afterwards is a pure function of time on the same clock, so you can scrub it, slow it down or pause it. Plain SVG DOM, ESM and import maps, zero third-party runtime dependencies (it builds on @awacloud/fw).

  • SVG nodes in the scene
  • runs under fw's sanity lockdown (Math.random and performance.now are blocked on this page)
  • the same time always draws the same frame

Run it locally

From the repository root: bun cli.ts local_web --config cnf/local_web/dev.config.json, then open this page. Running the standalone build; append ?variant=fw to run it registered on an @awacloud/fw runtime. Technique map: neon-boot-notes.md.
