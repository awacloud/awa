Scene — JSON → SVG scene/event DSL

A traffic light built from a JSON scene spec (scene.json) via graphic.scene. Click a lamp to fire its named event: the yellow lamp fires warn, the green lamp fires go, the red lamp fires stop.

No build step: this page runs straight off the filesystem via a static server. Running the standalone build. Append ?variant=fw to the URL to run it registered on an @awacloud/fw runtime instead.
