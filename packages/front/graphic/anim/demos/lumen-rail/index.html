Lumen Rail — a rail shooter in SVG

Fly the Kite down a dusk lane: drones come in waves, pylons stand in the way, and the Warden waits at the end of a one-minute run. The lasers fire on their own. The scene is built once; each frame only moves pooled sprites, on the package's shared scheduler, with the svg3d kernels for the perspective.

Steer: arrow keys / WASD, or drag on the scene.

Reduced motion is on: the game waits for Fly or the autopilot.

No build step: this page runs straight off the filesystem via a static server. Running the standalone build; append ?variant=fw to run it registered on an @awacloud/fw runtime. Technique map: lumen-rail-notes.md.
