Every demo boots on either fw surface. Append ?variant=fw to a demo's URL to run it registered on an @awacloud/fw runtime instead of the default framework-free standalone build.

Functional legs: three demos now exercise the CORRECTED path behind an earlier "demos not fully functional" assessment — pageflip's guard against overlapping turns, hypertree's stop()/focusSync() guard-release seam, and svg3d's composed Svg3d class (the small inset panel, built from a dedicated prebuilt root, next to the main leaf-kernel terrain). Each leg is asserted, not just displayed — see tests/demos-smoke.integration.test.js in the repository.

This index is a static gallery — no @awacloud/fw is loaded at runtime here; each linked demo loads its own sanity lockdown.

Serve from the repo root — bun cli.ts local_web --config cnf/local_web/dev.config.json
