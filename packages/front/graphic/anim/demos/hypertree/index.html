Hypertree — radial tree with click-to-focus

A 25-node, 3-level tree (tree.json) built via graphic.hypertree. Click a node to recentre and fan its subtree over the full circle. The re-entrancy guard (ignoreWhileFocusing: true) is on: a click landing while a focus transition is in flight is dropped rather than stacking a second transition. Every click reports through onNodeClick, every completed focus reports through onFocus(id, info) below. Two seams beyond this page's own UI are exercised in tests/demos-smoke.integration.test.js: cancelling a focus directly via its returned Timeline#stop() still releases the guard, and focusSync() wins over an in-flight focus().

Click a node to focus it.

No build step: this page runs straight off the filesystem via a static server. Running the standalone build. Append ?variant=fw to the URL to run it registered on an @awacloud/fw runtime instead.
