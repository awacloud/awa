Clock — legacy clock.js reproduction (acceptance demo)

An analog clock reproducing the legacy @anim-old clock.js dial (masked circles, three hands) using ONLY the modern graphic.anim aggregate: graphic.scene + graphic.svgBuild for structure, graphic.tween + graphic.scheduler for the true-clock-rate hand rotation. See clock-notes.md for the construct-by-construct map and the honest gap list.

No build step: this page runs straight off the filesystem via a static server. Running the standalone build. Append ?variant=fw to the URL to run it registered on an @awacloud/fw runtime instead.

Source: packages/front/graphic/anim/demos/clock/
