Easing lab — every curve, one dot

Pick any of the 31 graphic.easing curves and watch a dot glide along a track using it, right next to the curve's own shape plotted below. The curve list is never hardcoded — it is Object.keys(easing) off the resolved graphic.easing surface. See also the sibling timeline-lab playground.

No build step: this page runs straight off the filesystem via a static server, and resolves its own @awacloud/fw runtime — it does not share the demos/ family's boot helper.
