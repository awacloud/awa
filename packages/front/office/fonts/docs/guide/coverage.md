# Coverage

What `@awacloud/fonts` is measured against: public suites, external validators, wild inputs and published benchmarks.

## Reading the leaderboard figure

`text-rendering-tests-outline` draws the glyphs of the 63 static outline
cases of the Unicode text-rendering-tests from the package's read APIs
(no shaping: the suite's shaping and variation cases are not run) and
compares them with the expected outlines. The cases that do not pass all
fall on features the package does not implement yet: CID-keyed CFF fonts
(their `FDSelect` / `FDArray`), CFF accented glyphs built with `seac`,
CFF charset glyph names, and Macintosh `cmap` subtables, which are read
as if they were Unicode.
