# Coverage

What `@awacloud/oconv` is measured against: public suites, external validators, wild inputs and published benchmarks.

## Reading the leaderboard figures

Both benchmarks below score the `pdf → md` direction, `toMd` on PDF files
other projects chose. `toMd` reads the text layer only: there is no OCR,
so a scanned page gives no text.

- `pypdf-benchmarks-read` compares the extracted text with a ground truth,
  character by character, on 14 born-digital PDFs. It measures text
  extraction and reading order, not structure.
- `opendataloader-bench` averages three scores: reading order (NID),
  tables (TEDS) and headings (MHS). Its 200 PDFs are untagged, and on an
  untagged PDF the reader emits paragraphs only: it recovers no heading
  and no table, so the table and heading scores are 0 and the overall
  figure rests on reading order alone. Inferring headings and tables from
  the layout of an untagged PDF is not implemented; a tagged PDF's
  structure tree is read (see the [loss matrix](../loss-matrix.md)).
