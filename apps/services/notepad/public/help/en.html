AWA Notepad writes and edits plain-text files on your device, online or offline. Nothing is uploaded: your files are opened and saved by your browser, on your computer.

Open, save, rename

  • Open (Ctrl+O), or drop a file on the page. Several files at once: the first opens; the others wait on a line under the header, and each Open … in a new window opens the next one.
  • In Chrome and Edge, Save (Ctrl+S) writes back to the file you opened; Save as (Ctrl+Shift+S) asks where.
  • Firefox and Safari cannot write back to a file: the button says Download a copy, and each save puts a new copy in your downloads.
  • The document's name is in the toolbar: click it to rename. In Chrome and Edge the file itself is renamed when the browser allows it; otherwise the name is used for the next save.
  • Binary files and files over 16 MB are refused, never damaged. Large files are read with a progress bar and a Cancel; past a few MB, typing gets slower (a limit of the browser's text area).

Edit, find, undo

  • Find (Ctrl+F) marks every match in the text as you type and outlines the current one; Enter or F3 goes to the next, Shift+F3 to the previous.
  • Replace (Ctrl+H): one at a time, or all. Go to line (Ctrl+G).
  • Undo (Ctrl+Z) and Redo (Ctrl+Y): typing is undone a word group at a time, and Replace all or the date (F5) in one step.
  • Word wrap, and the text size (Ctrl+wheel too), are remembered.

Encodings and line endings

The status bar shows how the file is written: line endings (Windows CRLF, Unix LF, old Mac CR) and the encoding (UTF-8, UTF-8 with BOM, UTF-16, Windows-1252). Both are detected when the file opens and kept when you save; change them from the status bar. Saving characters Windows-1252 cannot hold asks first.

Unsaved text comes back

While you type, your changes are kept on this device. If the window closes before you save (a crash, a closed tab, an update), the next window of the notepad brings the text back, still unsaved — and in Chrome and Edge, still linked to its file. A window that is open keeps its own text: a second window never takes it.

Install the app

Chrome, Edge

Use the Install button in the header when it appears, the install icon in the address bar, or the browser's menu (Install AWA Notepad or Apps → Install this site as an app).

Firefox (Windows)

Use the Add to taskbar button in the address bar.

Safari

On a Mac: File → Add to Dock. On an iPhone or iPad: Share → Add to Home Screen.

Open your files with the app (Windows)

Installed from Chrome or Edge, the notepad appears in Open with when you right-click a text file (.txt, .md, .json, .log, source and configuration files…). To make it the default: Settings → Apps → Default apps. Each file opens in a window of its own.

Updates

A new version installs in the background and never interrupts you: a line in the header says a new version is ready; Update now reloads the notepad and your unsaved text comes back (or choose Later). To check yourself: About → Check for updates.

Offline and privacy

Once visited (or installed), the notepad works without a connection. Your text is never sent anywhere.
