Open a document

  • Drop a file on the page, or choose Open (Ctrl+O).
  • Formats: PDF, Word (DOCX), Excel (XLSX), PowerPoint (PPTX), OpenDocument (ODT, ODS, ODP), Markdown and text files. Older Office files (DOC, XLS, PPT) are recognised but not opened yet.
  • No document at hand? Under the drop zone, Try a sample opens one of our showcase documents.
  • Several files at once: the first opens; the others wait on a line under the header, and each Open … in a new window opens the next one.

Read and move around

  • PDF pages and slides: Previous and Next, or type a page number.
  • Zoom: the zoom buttons and menu, or Fit width. Spreadsheets have one tab per sheet under the grid.
  • Full screen, and Download to save the original file.
  • Details (the i button) shows the file's details and what this view leaves out: anything the viewer could not draw is listed there, never hidden.

Install the app

Chrome, Edge

Use the Install button in the header when it appears, the install icon in the address bar, or the browser's menu (Install AWA Viewer or Apps → Install this site as an app). The app then has its own window and icon.

Firefox (Windows)

Use the Add to taskbar button in the address bar.

Safari

On a Mac: File → Add to Dock. On an iPhone or iPad: Share → Add to Home Screen.

Open your files with the app (Windows)

Installed from Chrome or Edge, the viewer appears in Open with when you right-click a document. To make it the default app for a type of file: Settings → Apps → Default apps. Each file opens in a window of its own.

Updates

A new version installs in the background and never interrupts you: a line in the header says A new version of the viewer is ready; choose Update now, or Later. To check yourself: About → Check for updates.

Offline and privacy

Once visited (or installed), the viewer works without a connection. Your documents are never sent anywhere; the only files the page loads are its own and, when you ask for one, a sample.
